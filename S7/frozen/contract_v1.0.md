## 2. 冻结对象

| 指数        | 定义                              | NHANES III 第二次检查              | NHANES 2001–02 复测（407 对） |
| --------- | ------------------------------- | ----------------------------- | ------------------------ |
| NLR / GLR | 中性粒（或粒细胞）/ 淋巴细胞绝对数              | 若血常规为三分类，用粒细胞，记为 GLR          | NLR                      |
| PLR       | 血小板 / 淋巴细胞绝对数                   | ✓                             | ✓                        |
| SII       | 血小板 × 中性粒（粒细胞）/ 淋巴              | ✓（SII_g）                      | ✓                        |
| SIRI      | 中性粒 × 单核 / 淋巴                   | 仅当两次检查都有单核（或单个核）绝对数；记为 SIRI_g | ✓                        |
| TyG       | ln(TG[mg/dL] × 空腹血糖[mg/dL] / 2) | 仅当两次检查均空腹 ≥ 8 h               | 仅当两次抽血均空腹 ≥ 8 h          |

成分（一并报告）：中性粒/粒细胞、淋巴、单核/单个核、血小板、TG、空腹血糖。 参照行：PhenoAgeAccel（取自 REL-01 主分析）。

所有指数取自然对数后计算 ICC 与每 SD 的 HR。

## 3. 分层任务

### A1 变量语义（任一项不明 → 该指数 `NOT_RUN`，不影响其他指数）

对每个指数、每个数据集写出：两次测量的确切变量名与单位；血常规分类方式（五分类 / 三分类）；两次检查的仪器或方法是否相同；两次各自的空腹时长变量。

### A2 人数门

在 REL-01 的分析样本内，某指数两次均有效的人数：

- NHANES III：≥ 900 人（约为 1,801 的一半）；
- 2001–02：≥ 270 对（约为 407 的 2/3）。

不足 → 该指数 `NOT_RUN`。TyG 因空腹配对不足而 `NOT_RUN` 时，不换成非空腹版本。

### A3 校准（确认 S7 代码路径与主分析是同一样本）

用 S7 的代码路径重算 PhenoAgeAccel 的 ICC 和同人 HR，必须与 REL-01 冻结包的输出一致：ICC 差值 ≤ 0.005；log HR 差值 ≤ 0.01；样本人数与死亡数完全一致。不过 → `CALIBRATION_FAIL`，先修代码路径；修不好则 S7 整体 `NOT_RUN`。

### B 计算

对每个指数、每个成分，以及参照行 PhenoAgeAccel：

1. ICC（95% CI）、CVw、MDC95；
2. 四分位重分类率：第一次在 Q4 者第二次不在 Q4 的比例（95% CI）；
3. 仅限 NHANES III：分别以第一次、第二次、两次均值为暴露的每 SD HR；第一次与第二次的 log HR 差值（95% CI）；p < 0.05 判定是否在两次之间翻转；
4. **与 PhenoAgeAccel 的配对比较**：采用同一套人级 bootstrap 重抽样（与 REL-01 相同的次数和种子），计算 ICC(指数) − ICC(PhenoAgeAccel) 的 95% CI。

### 措辞规则（冻结）

- 差值 CI 不含 0 时，才可写"比 PhenoAgeAccel 更 / 更不可靠"；否则只写"可比"。
- 摘要与主要结论保持不变；正文只加一段结果和一张补充表，并标注为事后分析。
- 若使用了 GLR / SII_g / SIRI_g，表注说明其与现行五分类 NLR/SII/SIRI 的定义差别。
